# Localization terms

Use these terms in `ramnotes/App/Localizable.xcstrings`. System terms follow macOS. App terms follow the [glossary](GLOSSARY.md).

The translations still need native-speaker review. Update this list before changing a term across the catalog.

## Fixed rules

- Keep `RAMnotes`, `iCloud`, `UTF-8`, `.txt`, `esc`, and the modifier symbols ⌃ ⌥ ⇧ ⌘ unchanged.
- Keep `Finder` unchanged, except in Simplified Chinese, where Apple uses 访达.
- Keep `Dock` unchanged, except in Simplified Chinese, where Apple uses 程序坞.
- Keep the ellipsis `…` on menu items and buttons that open a panel. German puts a space before it, as Apple does (`Einstellungen …`).
- Use title case in menu titles only where the language uses it (English, Brazilian Portuguese menu items follow Apple's capitalization).
