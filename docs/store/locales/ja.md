## Description (4000 characters)

RAMnotesはMac用の付箋メモアプリです。ショートカット1つでメモを表示し、同じショートカットでまた隠せます。メモは1つずつテキストファイルなので、AIツールからも読んだり編集したりできます。

【表示と非表示】
• どのアプリを使っていても、Control + バックスラッシュで開いているメモを表示したり隠したりできます。
• ポインタをメニューバーに置いてスクロールする方法もあります。
• ショートカットは「設定」で変更できます。
• メモは前回止めたところから開きます。
• Dockにもメニューバーにもアイコンは表示されません。

【AIプロジェクトでメモを使う】
例：
1. プロジェクトフォルダに agent-inbox.txt という名前でメモを保存します。
2. 作業しながら、タスクやリンク、アイデアをメモに書いていきます。
3. AIツールにこのファイルを読むよう指示します。たとえば AGENTS.md や定期実行のタスクでファイルを参照します。
4. AIツールがタスクを実行し、ファイルを編集します。
5. RAMnotesでメモを開くと、変更内容を確認できます。

RAMnotesにAI機能はありません。RAMnotesが行うのは.txtファイルの読み書きだけで、それ以外の手順はAIツールが受け持ちます。

【好きなフォルダにメモを置く】
メモはMac上のどのフォルダにも置けます。メモごとに別のフォルダでもかまいません。
• 新規メモを保存する「デフォルトのメモフォルダ」を設定できます。
• 「移動…」で、メモを別のフォルダに移せます。
• Finderから.txtファイルを追加すると、ファイルを移動せずにその場で編集できます。

ほかのアプリからも同じファイルを読んだり変更したりできます。メモを同期したい場合は、デフォルトのメモフォルダを iCloud Drive、Google Drive、Dropbox などのサービスのフォルダに設定してください。

【メモウインドウ】
• 複数のメモを同時に開けます。
• 「メモウインドウを常に手前に表示」をオンにすると、メモがほかのアプリより手前に表示されます。
• 背景の色合いは6色から選べます。
• フォントサイズはメモごとに設定できます。Command + プラス記号（+）で大きく、Command + マイナス記号（-）で小さくなります。
• ウインドウの位置と、メモごとに作業していた位置を記憶します。
• 変更内容は自動的に保存されます。

【検索】
• Command + F で、表示中のメモ内を検索します。
• Shift + Command + F で、すべてのメモを検索します。
• メモリストにも検索フィールドがあります。

【設定】
• デフォルトのメモフォルダ
• フォント、デフォルトのフォントサイズ、行間
• 外観（ライト/ダーク）
• ショートカット
• ログイン時に起動

【プライバシー】
RAMnotesはインターネットに接続しません。アカウントは不要で、データも収集しません。読み書きするのは、選択したファイルとフォルダだけです。

【制限事項】
• プレーンテキスト専用です。リッチテキスト、Markdownのプレビュー、タグには対応していません。
• メモはUTF-8の.txtファイルである必要があります。
• メモリストは、デフォルトのメモフォルダ内のサブフォルダまでは読み込みません。
• RAMnotes独自の同期サービスはありません。

【対応言語】
英語、スペイン語、ポルトガル語（ブラジル）、ドイツ語、フランス語、アラビア語、日本語、簡体字中国語

【動作環境】
macOS 27.0以降を搭載したApple Silicon Mac
