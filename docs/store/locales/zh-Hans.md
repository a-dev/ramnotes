## Description (4000 characters)

RAMnotes是Mac上的便签应用。按一个快捷键显示笔记，再按一次就隐藏。每个笔记都是一个文本文件，你的AI工具可以读取和编辑。

显示和隐藏
• 在任何应用中，按Control-反斜杠即可显示或隐藏打开的笔记。
• 也可以把指针移到菜单栏上滚动。
• 快捷键可以在“设置”中更改。
• 笔记会在你上次停下的位置打开。
• RAMnotes没有程序坞图标，也没有菜单栏图标。

在AI项目中使用笔记
示例：
1. 在项目文件夹中存储一个名为 agent-inbox.txt 的笔记。
2. 工作时，把任务、链接和想法写进这个笔记。
3. 让AI工具读取这个文件，比如在 AGENTS.md 或定时任务中引用它。
4. AI工具完成任务，并编辑这个文件。
5. 在RAMnotes中打开笔记，查看改动。

RAMnotes本身没有AI功能。它只读写 .txt 文件，其余步骤由你的AI工具完成。

笔记可放在任意文件夹
笔记可以放在Mac上的任意文件夹中，每个笔记的文件夹也可以不同。
• 为新笔记设置默认文件夹。
• 用“移动到”把笔记移到其他文件夹。
• 从访达添加 .txt 文件，在原位置直接编辑。

其他应用也可以读取和修改这些文件。如需同步笔记，可将默认文件夹设为 iCloud Drive、Google Drive、Dropbox 或类似服务中的文件夹。

笔记窗口
• 可以同时打开多个笔记。
• “保持笔记窗口在最前面”让笔记显示在其他应用上方。
• 每个笔记可以选用六种背景色调之一。
• 每个笔记有自己的字体大小，可用Command-加号和Command-减号调整。
• RAMnotes会记住每个窗口的位置，以及你在每个笔记中看到的位置。
• RAMnotes会自动存储你的更改。

搜索
• 按Command-F在当前笔记中搜索。
• 按Shift-Command-F搜索所有笔记。
• 笔记列表中有搜索栏。

设置
• 默认笔记文件夹
• 字体、默认字体大小和行距
• 浅色或深色外观
• 快捷键
• 登录时启动

隐私
RAMnotes不连接互联网，无需账户，也不收集任何数据。它只读写你选择的文件和文件夹。

限制
• 仅支持纯文本。不支持富文本，没有Markdown预览，也没有标签。
• 笔记必须是UTF-8编码的 .txt 文件。
• 笔记列表不会扫描默认文件夹的子文件夹。
• RAMnotes没有自己的同步服务。

语言
英语、西班牙语、巴西葡萄牙语、德语、法语、阿拉伯语、日语和简体中文。

系统要求
搭载Apple Silicon的Mac，macOS 27.0或更高版本。
